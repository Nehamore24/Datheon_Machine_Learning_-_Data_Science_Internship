# Datheon – Machine Learning & Data Science Internship

Welcome to my project repository for the Datheon Machine Learning & Data Science Internship.

This repository contains three machine learning and data science projects completed as part of the internship.

## Projects

### 1. Iris Flower Classification
- Classification of Iris flower species.
- Exploratory data analysis and machine learning.
- Model training and evaluation.

**Notebook:** `Task_1_Iris_Classification.ipynb`

### 2. California House Prediction
- California housing dataset analysis.
- Data preprocessing and machine learning regression.
- Housing price prediction and model evaluation.

**Notebook:** `Task 2 California House Prediction.ipynb`

### 3. Customer Churn Prediction
- Telecom customer churn prediction.
- Data preprocessing and One-Hot Encoding.
- SMOTE for handling class imbalance.
- Random Forest and XGBoost classifiers.
- ROC-AUC evaluation and feature importance analysis.

**Notebook:** `Task 3 Customer_Churn Prediction.ipynb`
